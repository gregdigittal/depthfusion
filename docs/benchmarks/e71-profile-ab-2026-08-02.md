# E-71 Profile A/B Benchmark — S-236 T-820
**Date:** 2026-08-02  **Environment:** VPS (vps-cpu mode)

## Purpose

Gate the CIQS ≥95 projection in the README by measuring retrieval quality under
`--profile standard` (BM25) vs `--profile research` (intended: real embeddings).
Validates the `--profile` flag added in T-818 and the paired Wilcoxon signed-rank
test added in T-819.

## Runs

| Run file | Profile | Embedding backend |
|---|---|---|
| `2026-08-02-vps-cpu-run4-raw.jsonl` | `standard` | BM25 (env: default) |
| `2026-08-02-vps-cpu-run5-raw.jsonl` | `research` | BM25 (env: `OPENAI_API_KEY` not set → BM25 fallback) |

Both runs: Category A (Retrieval Quality), 3 topics × 5 blocks each, no errors.

## Outcome

**Zero delta.** Both profiles returned identical block counts with BM25 retrieval.
This mirrors S-227 A/B (same finding).

The research profile overrides enable cognitive scoring, graph traversal, fusion gates,
and caching — but the retrieval backend remains BM25 until `OPENAI_API_KEY` is configured
in the server environment and `DEPTHFUSION_EMBEDDING_BACKEND=openai` is set.

## Wilcoxon test status

The `wilcoxon_signed_rank` implementation (T-819, `scripts/ciqs_harness.py`) and its
36-test validation suite (`tests/benchmarks/test_wilcoxon.py`) are shipped and ready.
The test will be meaningful once an embedding comparison produces non-zero differences.

## CIQS ≥95 gate

**NOT CLEARED.** The ~95–97 projection cannot be confirmed or refuted from BM25-only
data. The gate requires:

1. `OPENAI_API_KEY` configured in the VPS environment
2. `DEPTHFUSION_EMBEDDING_BACKEND=openai` set for the research-profile run
3. Both profiles producing Category A scores
4. Wilcoxon p < 0.05 OR negligible effect size confirming no regression from BM25

The README footnote `¹ pending real-embedding validation (E-71)` remains.
